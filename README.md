# Machine Learning Lab

This repository contains machine learning laboratory exercises implemented in Python notebooks. The notebooks cover data loading and exploration, visualization, regression, classification, regularization, and model evaluation with common Python data science libraries.

## Contents

- `Activity_1.ipynb`: Linear, Ridge, and Lasso regression with error evaluation.
- `lab_1.ipynb`: Data loading, cleaning, and exploratory analysis.
- `lab_2.ipynb`: Decision tree classification and evaluation.
- `lab_3.ipynb`: Linear regression exercises using external datasets.
- `lab_4.ipynb`: Additional linear regression and error analysis exercises.
- `lab_5.ipynb`: Regression with preprocessing and model evaluation.
- `lab_6.ipynb`: Linear, Ridge, and Lasso regression comparison.

## Requirements

- Python 3.9 or later
- Jupyter Notebook or JupyterLab
- NumPy
- pandas
- Matplotlib
- Seaborn
- scikit-learn

Install the required packages with:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
```

## Running the Notebooks

1. Clone the repository:

   ```bash
   git clone https://github.com/nikshep-root/ml-lab.git
   cd ml-lab/Machine_Learning_Lab
   ```

2. Start Jupyter:

   ```bash
   jupyter notebook
   ```

3. Open a notebook and run its cells in order.

Some laboratory notebooks refer to datasets stored outside the repository, including `mydata.csv`, `dataset.csv`, and `dataset_csv.csv`. Place the required files in the notebook's working directory before running those exercises.
